Pipeline Overview

This pipeline extracts and aligns monomers from centromeric satellite DNA arrays for phylogenetic analysis. The workflow uses ArraySplitter to decompose tandem repeat arrays into individual monomer units, then rotates them to a common starting position for multiple sequence alignment.

6Monomer Rotation

Method: Finding Optimal Rotation K-mer

  1. K-mer selection: Find k-mer that appears exactly once in maximum number of monomers
  2. Sequence doubling: Search in seq+seq to handle cases where k-mer spans tandem boundary
  3. Approximate matching: Allow up to 5 mismatches (edit distance) to handle point mutations
  4. Strand normalization: Check both forward and reverse complement, use best match

Main Finding

CDR and flanking regions contain the same 716bp satellite DNA family. The 696bp consensus is 100% identical, and 717bp differs by only 8 nucleotides (98.88%).

Key Difference

CDR has 10x higher sequence heterogeneity than flanking regions (31-33% vs 2.7-3.8% sequences with rare indels). This suggests active centromere function drives sequence diversification.

Biological Interpretation

  • Same repeat family: Both CDR and flanking arrays derive from the same ancestral 716bp satellite DNA.
  • CDR-specific diversity: Active centromere regions accumulate more mutations/indels, possibly due to:
    • Kinetochore binding pressure
    • Higher recombination rates
    • Centromere drive mechanisms
  • Flanking conservation: Pericentromeric flanking repeats are under different selective pressure, maintaining higher homogeneity.
  • Two length variants: The 21bp length difference (717 vs 696bp) represents a stable deletion variant present in both CDR and flanking regions.

Scientific Questions & Hypotheses

Key Finding

Weak correlation (r = 0.17) between chromosome length and centromeric array size. Small chromosomes have higher density of centromeric monomers than large chromosomes.

H1 CDR size is independent of chromosome length

Kinetochore assembly may require a minimum threshold of centromeric DNA regardless of chromosome size. This would explain why small chromosomes have proportionally larger centromeres.

Test: Compare CDR absolute size (bp) across chromosomes. If H1 is true, absolute size should be similar (~25-30 kb).
H2 Functional constraint on kinetochore size

The kinetochore may require a minimum number of CENP-A nucleosomes for stable spindle attachment. CDR size reflects this functional requirement, not chromosome mass.

Test: Cross-reference with CENP-A ChIP-seq data if available. Kinetochore footprint should correlate with CDR size.
H3 Evolutionary dynamics differ by chromosome

Microchromosomes may have different centromere expansion/contraction dynamics than macrochromosomes. Selection pressure or recombination rates could vary.

Test: Compare monomer sequence diversity between macro (>50 Mb) and micro (<10 Mb) chromosomes via MSA.
